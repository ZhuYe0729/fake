# 140 DASO 海光团队交流汇报计划

## 目标与假设

- 制作约 5 页、中文为主、16:9 的简洁学术交流 PPT，沿论文的问题—观察—方法—实验—展望逻辑组织。
- 面向推理团队进行初次交流，默认无需展开公式、求解器和 kernel 实现细节；第一页兼顾标题和问题背景。
- 以 `artifacts/paper/wu.tex` 和 `daso/results/paper/` 的最终版本为依据；区分已经完成的 Dense Llama 实验和待探索的大模型 / MoE 合作方向。
- 海光平台的型号、算子支持与可用资源尚未确定，使用条件性合作议题，不承诺已有适配或性能收益。
- 按用户要求，将汇报及生成材料独立存放在 `artifacts/presentations/daso_hygon/`。

## 页面安排

1. DASO 与部署决策问题：压缩方法丰富，但模型、硬件、负载和质量需求不同。
2. 关键观察：同一种方法在不同推理阶段收益不同，模块敏感度也不同，形成细粒度组合的动机。
3. 方法框架：时延与质量建模、质量预算下的策略优化、推理运行时执行；用简图说明流程。
4. 实验结果：最终 RTX 5090 两模型结果与代表性质量—速度图，补充跨平台验证事实。
5. 后续合作：海光平台适配、更大模型和 MoE 的分步验证，以及希望共同投入的资源。

## 实施与验收

1. 核实正文和结果数据，整理简短讲述内容 → 验证数字与最终表格一致。
2. 生成可编辑 PPTX、PDF 和页面预览，保留本地生成脚本与必要素材 → 验证为 5 页且正文与图表清晰。
3. 检查文字溢出、中文字体、布局和引用；记录实现与复建方式 → 交付独立目录和可直接打开的文件。
