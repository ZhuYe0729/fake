# 139 DASO 正确性修复与开源收口计划

## 目标

修复代码审查确认的求解器预算离散和质量截距问题，确保论文结果目录只有唯一正式版本，并补全结果验证、外部后端契约、依赖声明和额外模型的最小可执行入口。

## 实施步骤

1. 修复 DP 离散预算并将质量模型截距贯穿 action table、求解和报告；用边界测试验证策略不会超过真实质量预算。
2. 整理 canonical/legacy 论文表，改造 archive validator 为结构化来源与单元格检查，并对公开文本结果做确定性路径脱敏。
3. 固定评测依赖和外部 vLLM/CUTLASS 版本契约，明确许可证、论文构建资源和历史证据缺口。
4. 为 MaxViT、DINOv3、MIRROR 和 FakeVLM 补充配置驱动的最小评测入口与 smoke tests。
5. 执行单元测试、工作流回放、manifest、路径审计和 CPU quickstart，并记录限制与结果。

## 验收标准

- 所有 solver 返回值使用原始浮点代价验证后均满足总质量预算。
- 质量模型 `bias` 不再被静默忽略，输出可拆分为 intercept 与 action cost。
- 正式表格与最终论文一致，旧表仅存在于明确标记的 legacy 目录。
- 验证器能定位具体来源行和表格单元格，错误数值或错误 metric 会失败。
- 项目测试和可离线执行的 smoke checks 全部通过。
