# Llama3.1-8B-Instruct ablation consolidation

This directory is the portable, paper-facing consolidation of all completed
ablation experiments. It does not modify the main experimental results.

## Contents

- `ablation.tex`: ablation-only LaTeX section ready to copy into a paper.
- `summary.md`: protocols, results, interpretation, and source mapping.
- `data/`: raw measurements and machine-readable summaries.
- `figures/`: paper-facing and audit figures in PNG/PDF formats.
- `tables/`: standalone LaTeX tables generated by the source experiments.
- `docs/`: detailed source reports and modeling documentation.
- `reproduction/`: the scripts used by experiments 064--066.
- `source_manifest.json`: source path, destination, byte count, and SHA256 for
  every copied file.

The 12 GB runtime checkpoint is intentionally excluded. Its policy and export
provenance are retained, and the checkpoint can be regenerated using the
runtime reproduction scripts and source experiment 057.

Rebuild the copied artifacts and validate them with:

```bash
/home/agent/wja/miniconda3/envs/cospaq/bin/python scripts/build_consolidation.py
/home/agent/wja/miniconda3/envs/cospaq/bin/python scripts/validate.py
```
