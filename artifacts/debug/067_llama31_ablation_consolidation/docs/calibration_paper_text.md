**Calibration-size sensitivity.** We keep the 18-policy holdout fixed and refit the unchanged phase-aware quality surrogate using nested subsets drawn from one 72-policy candidate pool. Every subset retains the five dense/uniform anchors, while ten fixed random orders quantify subset variance. Under a preregistered criterion that selects the smallest calibration size remaining within 5% of the full-model MAE, the observed elbow occurs at 72 policies. The independently frozen 54-policy main model requires 48.6 GPU-minutes. The full 72-policy pool requires 46.7% more labeling cost and reduces holdout MAE by a further 17.6% relative to that particular subset. We mark the frozen main model separately from the random-pool sensitivity curve to avoid post-hoc subset selection.
