- 旧测量Max-speed的Decode TPOT三轮为8.695/8.603/7.085 ms，TTFT约520–524 ms，变化主要发生在Decode。其第一轮5次E2E为1077/1084/1072/1059/981 ms，不能仅归因于某一个孤立坏点。
- 两个固定配置的轮间排序发生变化，中心速度比范围也有重叠；旧中心行不能据此解释为稳定的两点速度优劣，更不能把Max-speed理解成每个负载的最优解。
- 048中Max-speed三轮均略快（约0.7%），但两次输入token全16384处不同；040捕获B1/B8、max_model_len=4168、max_num_batched_tokens=32768，048只捕获B8、对应2120/16384。因此048不是严格控制的040复测，也不能将其中心值替入040。
- 保存的CPU/频率样本随进程有变化，只能作为后续诊断线索。GPU/CPU或运行路径中哪项导致波动，现有日志尚未给出因果结论；没有证据将慢轮直接删除。
- 表中±2SE是NLL质量统计，并非计时误差。如果指平均ΔNLL，旧中心Balanced确实比Max-speed小（0.00861 vs 0.01418）；这是该组样本的质量点估计，不代表整个负载范围都全面更好。
- 需要补的严格复测：固定同一引擎、输入、GPU、CPU/NUMA与运行路径，在相同协议下交错重复两点和强参考；提前固定全部重复与汇总规则，保留全部轮次。未执行该新GPU实验，本文仅复核已有日志。
