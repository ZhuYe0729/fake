# Qwen3-8B：固定配置的六种负载迁移（R2 Exi5 / R3 LrT2 / R4 QboE）

11行方法标签、10套唯一配置、6种负载全部保留。配置来自已封存主表，未按新负载重优化或筛选；ε是中心选择标签，不代表新负载质量保证。

同RTX5090 GPU0/NUMA0 CPU0–7、6GiB BF16 KV、native decode Graph，整批KV容量逐项检查。每策略/轮次只初始化一个引擎，依次运行六种负载，每负载3 warmup+5 timed。三轮不同顺序，BF16首尾锚点，表中归一化加速中位数；三轮范围另报，不是置信区间。TTFT取实际首token，TPOT=(E2E−TTFT)/(O−1)，cycle包含请求间恢复。

每负载在64个固定WikiText-test窗口实测教师强制decode NLL，batch与测速一致；误差为paired ±2SE的描述性范围。不同负载共用源起点以减少数据差异；该公开语料以前已经整体评测，不能声称全新未见语料。
