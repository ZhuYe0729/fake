# R1：P+D多负载预算满足率（既有完整18设定）

统计范围为Qwen3-8B、Run003冻结的全部DASO workload adapted P+D设定：9种负载×ε=0.01/0.07两档预算，使用原DP七候选扩展，未作额外validation筛选。所有预设点均纳入，不按是否超限筛选。

共18个预算—负载检查，17/18（94.4%）测试平均ΔNLL满足预算，1/18（5.6%）超限；对应16套唯一method-map。每点100个固定WikiText测试窗口，两个预算/不同负载复用文本，并非18次独立随机试验。

ε=0.01：8/9满足、1/9超限；ε=0.07：9/9满足、0/9超限。只能描述这组预设网格的分布，不据此证明一般违约概率随预算收紧而上升。

唯一超限：B=8、输入=512、输出=64，ε=0.01，预测ΔNLL=-0.00047371，实测平均ΔNLL=0.01195875，超限0.00195875 nats/token。配对SE=0.00729144，原描述性95%配对bootstrap区间[-0.00312184, 0.02537248]。

质量模型保持中心负载校准参数不变；各负载更新动作延迟并重新分配，检验冻结质量代理的跨B/S/O迁移。模型并未在这些测试结果上重拟合。本次只独立重算历史NLL，不使用旧速度来替代最近053正式速度。

选点预测MAE：ε=0.01为0.00428，ε=0.07为0.03757。较宽预算存在保守预测，不声称每个点均预测精确；均值满足率不等于单请求保证或下游任务等效。
