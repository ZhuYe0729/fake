## 本轮观察

原权重下，预算从.04收紧至.01，稀疏FP4 prefill从21减至3个，生成Avg从28.709升至30.012，MC Avg从64.379升至69.561。小权重主要沿收紧预算的方向移动，λ2/.03与原权重.02完全重合。

w32_e0.03：生成Avg 29.951（相对INT8 +0.233），MC Avg 69.765（相对INT8 -0.201、相对SQ-INT8 -0.811个百分点），E2E为同轮INT8的1.240倍速度（三轮范围1.227–1.266）。实际NLL保护值0.03350，名义加权预算.03。

w128_e0.03：生成Avg 29.901（相对INT8 +0.182），MC Avg 69.379（相对INT8 -0.588、相对SQ-INT8 -1.197个百分点），E2E为同轮INT8的1.190倍速度（三轮范围1.174–1.205）。实际NLL保护值0.03755，名义加权预算.03。

这些点表明提高prefill权重能在完整自由搜索中改变分配、改善生成质量折中；仍不能宣称所有任务全面超过8bit，或实测NLL保护值满足.03。两个大权重点的decode也都全W4，在这一固定decode子空间内同样可以重参数化成原预算；本轮没有证明它们优于更密的原预算曲线。λ32/128属于探索性阶段权重敏感性结果，不能仅据本表宣布通用默认参数；原代理阶段尺度和真实任务质量仍有差距。
