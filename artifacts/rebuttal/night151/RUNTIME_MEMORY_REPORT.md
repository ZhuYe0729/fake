# 三模型阶段表示、传输与完整cycle（R1 AK6a / R3 LrT2 / R5 gkP9）

各项为三轮中位数，P+D为B8/S2048/O64。GPU0/NUMA0；Qwen/Llama-3.1 KV6GiB，Llama-2 KV10GiB。初始化Torch峰值与全进程Torch峰值分列，后者包含初始化；未在初始化后重置峰值，不能叫纯运行期峰值。NVML仅在每次生成结束时采样，报告这些样本的最大已用值，不是连续采样的真实瞬时峰值。同进程若测PP和P+D，内存统计跨两个场景，不能当成P+D独立峰值。

Linear storage只统计线性层GPU唯一storage，arena是其中子项；两者均非模型总显存。host cache为阶段权重唯一storage，不能与pinned或RSS重复相加。E2E不含请求间恢复，cycle包含恢复。
